📱 Asistencia – App móvil en Kotlin con Firebase
Aplicación móvil desarrollada como parte del Proyecto Integrador, enfocada en el registro y administración de asistencias utilizando Kotlin, Jetpack Compose y Firebase Firestore.
La app permite agregar, consultar, editar y eliminar registros en tiempo real desde un dispositivo Android.

🚀 Características principales
Registro de asistencias mediante un formulario sencillo.
Visualización de una lista con datos almacenados en Firestore.
Funciones completas de CRUD:
✔ Agregar
✔ Leer
✔ Actualizar
✔ Eliminar
Conexión en tiempo real con Firebase Firestore.
Interfaz desarrollada completamente con Jetpack Compose.
Integración directa con Firebase desde Android Studio.

🏗 Tecnologías utilizadas
Kotlin
Android Studio
Jetpack Compose
Firebase Firestore
Google Services Plugin
Gradle Kotlin DSL
